# toyaji ART WORK | Portfolio & Commercial Design

イラストレーター・デザイナー **toyaji** の公式ポートフォリオWebサイトのリポジトリです。
デジタルイラスト、アナログ手描き表現、ロゴデザイン、落書きスケッチの作品集とご依頼案内をまとめたレスポンシブWebアプリケーションです。

---

## 🎨 主な機能

- **作品ギャラリー（WORKS GALLERY）**
  - **カテゴリーフィルター**: デジタルイラスト / アナログイラスト / デザイン / ロゴ / 落書き の切り替え表示
  - **リアルタイム検索機能**: タイトル・説明文・制作ツール・クライアント名によるインクリメンタル検索
  - **詳細モーダル（Lightbox）**: 作品カードクリックで拡大画像と詳細メタデータ（ツール・クライアント・制作年・キャプション）を表示
- **デザイン・UI/UX**
  - ダーク / ライト テーマ切り替えボタン
  - レスポンシブデザイン（PC / タブレット / スマートフォン最適化）
  - スムーススクロール & アニメーションエフェクト
- **管理者・作品管理ツール (Artwork Manager)**
  - 隠しコマンド（キーボードタイプ等）による管理者認証画面呼び出し
  - 新規作品のドラッグ＆ドロップ画像アップロード・追加
  - 登録済み作品の編集・ドラッグ＆ドロップ並び替え・制作年順ソート・JSONエクスポート
- **お問い合わせフォーム & サービス案内**
  - 制作ご依頼案内・制作フロー・メールアドレスコピー機能・お問い合わせフォーム

## 🚀 ローカルでの実行方法

1. このリポジトリをクローンまたはダウンロードします。
2. ターミナルでプロジェクトディレクトリに移動し、以下のコマンドを実行します:
   ```bash
   python3 server.py
   ```
3. ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。

---

## 🌐 GitHub Pages での公開手順

1. GitHub上に新しいパブリックリポジトリを作成し、ファイルをプッシュします。
2. リポジトリの **Settings** > **Pages** を開きます。
3. **Branch** を `main` (または `master`) / `/ (root)` に設定して **Save** します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` にてポートフォリオWebサイトが公開されます。
